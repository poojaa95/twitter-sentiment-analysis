# Twitter Sentiment Analysis Dashboard

## Overview
Interactive Power BI dashboard analyzing tweet sentiments (Positive, Negative, Neutral).

## Key Insights
- **Total Tweets:** 27,482
- **Positive:** 31.2%
- **Negative:** 31.2%
- **Neutral:** 40.5%
- **Most common positive word:** "happy"
- **Most common negative word:** "sad"
- **Negative tweets are longest on average (84 chars)**

## Files
- `Twitter_Sentiment_Dashboard.pdf` - Dashboard export
- `Twitter_Sentiment_Analysis.pbix` - Power BI source file
- `tweets_dataset.csv` - Raw data

## Tools Used
- Power BI Desktop
- Data source: Kaggle Twitter Sentiment Dataset
